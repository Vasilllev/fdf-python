# FdF

Небольшая программа на Python для отображения каркасной изометрической модели из карты высот `.fdf`.

## Запуск

```bash
python main.py maps/elem.fdf
```

Карта содержит целые высоты, разделённые пробелами. Цвет можно указать после запятой, например `2,0xFF0000`.

## Проверки

```bash
pytest -q
mypy --strict fdf main.py
ruff check .
```
